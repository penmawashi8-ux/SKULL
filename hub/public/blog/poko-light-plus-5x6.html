攻略シリーズ第4回はプラス型 5×5・6×6の大型グリッドです。追いかけ法の基本はこれまでと同じですが、グリッドが大きくなるほど解なし配置が存在すること・最終行補正の判定が難しくなること・一手のミスが後の行全体に波及することの3点が大きな課題になります。集中力を保ちながら1行ずつ確実に進めるコツを解説します。

大型グリッドの基本データ

5×5 25マス / シード最大 2⁵=32通り / 難易度 ★★★
6×6 36マス / シード最大 2⁶=64通り / 難易度 ★★★

5×5 追いかけ法の手順

5×5でも追いかけ法の手順は変わりません。1行目→4行目まで「OFFの真下を押す」を繰り返し、最終行（5行目）の状態を確認します。

1行目を確認
↓
2行目で1行目を補正
↓
3行目で2行目を補正
↓
4行目で3行目を補正
↓
5行目で4行目を補正
↓
5行目（最終行）が全ONか確認 → OK でクリア

4行目・5行目に補正必要

→

OFF（消灯）

5×5の注意点：解なし配置が存在する

5×5プラス型はライツアウトの標準サイズであり、解なし配置が一定の割合で存在することが数学的に証明されています。全ての初期配置が解けるわけではないため、何度シードを変えてもクリアできない場合はリセットが最善策です。

5×5の解なし配置について

5×5プラス型では全 2²⁵ 通りの配置のうち、解なしのものが約1/4（4分の1）程度存在します。シードを20通り以上試してもクリアできない場合は解なしの可能性が高いのでリセットしましょう。

6×6 追いかけ法の手順と注意点

6×6も同じ手順です。1行目→5行目まで追いかけ、最終行（6行目）を確認します。ただし手順が長くなるため、以下の点に特に注意してください。

大型グリッドでの「最終行補正」の判定

グリッドが大きくなるほど、追いかけ法後の最終行に残るOFFのパターンが複雑になります。3×3では4通りのシードで済みましたが、5×5では最大32通り、6×6では最大64通りのシードが考えられます。

3×3 / 4×4

シードの試行数が少ない（4〜16通り）。最終行の補正がシンプル。体系的に1マスずつ試せる。

5×5 / 6×6

シードの組み合わせが膨大。ただし「最終行の状態」→「必要なシード」を対応させるテーブルを知っていれば効率的。

効率的なシード探しの方針

大型グリッドでは全通りを試すのは現実的ではありません。以下の方針で試すと効率的です。

  1. まずシードなしで追いかけを実行して最終行の状態を記録する
  2. 最終行のOFFが1マスなら：その列に対応する1行目のマスをシードにして再試行
  3. 最終行のOFFが複数マスなら：1行目を左から1マスずつシードにして再試行
  4. 上記で見つからなければ2マスの組み合わせに進む

大型グリッドの現実的な攻略方針

5×5・6×6は「必ず解ける」ものではありません。追いかけ法をミスなく実行し、シードを10〜20通り試してもクリアできない場合は「解なし配置」の可能性を考えて潔くリセットすることも重要な判断です。

集中してミスなく進めるコツ

大型グリッドでは手順が長くなるほど途中でのミスが増えます。1か所のミスが後のすべての行に影響するため、丁寧さが攻略のカギです。

確認しながら進む

  • 各行を補正したあと、その行が全ONになっているか目視確認してから次に進む
  • 複数のOFFがある行は、左から右へ1マスずつ順に真下を押す
  • 1つタップするたびに周囲のマスの変化を確認する習慣をつける

ゆっくりとしたペースを保つ

  • 時間を急がず、1手ごとに盤面を確認する
  • 「何行目を直しているのか」を常に意識する
  • 疲れてきたら一旦中断する（ミスが増えるため）

詰まったらリセットも有効

5×5・6×6では詰まったらリセットが正解なことがあります。解なし配置は時間をかけても解けないため、別の配置で挑戦する方が全体的な攻略体験として充実します。

大型グリッドの重要な注意点

全盤面が解けるとは限りません。「どうしても解けない」と感じたとき、それは実力不足ではなく「解なし配置に当たっている」場合がほとんどです。リセットは正しい判断です。

5×5・6×6 攻略まとめ

  1. 追いかけ法の手順は3×3・4×4と同じ（OFFの真下を押して1行ずつ直す）
  2. 5×5では約1/4の配置が解なし→詰まったらリセットを検討
  3. 6×6は手数が多いので途中ミスに要注意、1行ずつ確認しながら進む
  4. シードを10〜20通り試してもクリアできなければ解なし配置の可能性が高い
  5. 集中力を保つことが最大の攻略ポイント
