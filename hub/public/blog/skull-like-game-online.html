スカル（Skull）みたいなゲームをオンラインで無料プレイ
スカル好きにおすすめのブラフゲーム

2026.07.07 ｜ ボドゲ広場

「スカル（Skull）みたいなゲームをオンラインで遊びたい」——飲み会やボドゲ会でスカルの読み合いにハマった人なら、一度は探したことがあるはず。この記事では、スカルの魅力を整理しつつ、スカルにインスパイアされた無料・登録不要のブラウザゲーム「BOMB」を紹介します。URLを友達に送るだけで、今すぐスカルのような心理戦をオンラインで楽しめます。

スカル（Skull）とは？

スカルは、フランス発の名作ブラフゲームです。各プレイヤーは花3枚とドクロ（スカル）1枚のカードを持ち、手元に裏向きで積み上げていきます。頃合いを見て「場のカードを〇枚めくれる」と宣言（入札）し合い、最後まで競り勝った人が実際にカードをめくります。ドクロを踏まずに宣言枚数をめくり切れば成功——というシンプルなルールながら、嘘・ハッタリ・読み合いが濃密に詰まったゲームです。

ルールは1分で覚えられるのに駆け引きは無限に深く、「ブラフゲームの傑作」として世界中で愛されています。

スカルみたいなゲームを「オンラインで」「無料で」遊ぶには

スカルの読み合いをオンラインで楽しみたいなら、選択肢は大きく2つあります。

  • 本家スカルを遊ぶ：Board Game Arena（BGA）などの海外プラットフォームで公式版のスカルがプレイできます。ただしアカウント登録が必要です。
  • スカル系の無料ブラウザゲームを遊ぶ：登録もインストールも不要で、URLを共有するだけで始めたいなら、スカルにインスパイアされたブラフゲーム「BOMB」がおすすめです。

スカル好きにおすすめ——「BOMB」とは？

BOMB（ボム）は、当サイト（ボドゲ広場）がスカルに着想を得て開発したオリジナルのブラフ心理戦ゲームです。各プレイヤーはりんご3枚と爆弾1枚を持ち、カードを裏向きに積み上げて「〇枚めくれる」と宣言し合います。爆弾を踏まずに宣言枚数をめくり切れば勝ち点、踏めば手札を失う——スカルで熱かった「あの読み合い」がそのまま楽しめます。

BOMB 基本情報

プレイ人数2〜6人
プレイ時間約20分
ジャンルブラフ・心理戦
料金無料（登録不要）

スカルとBOMBの共通点

  • カードを裏向きに積み上げて「めくれる枚数」を宣言し合う入札システム
  • 実行者は自分のカードから先に全部めくるルール（自分に地雷があると自爆する緊張感）
  • 安全カード（花／りんご）と地雷カード（ドクロ／爆弾）による、シンプルで奥深い読み合い
  • 失敗すると手札が減っていき、選択肢が狭まっていくヒリヒリ感

BOMBならではの要素

  • エモート機能：💣や🍎のエモートを飛ばして相手を心理的に揺さぶれる、オンラインならではの駆け引き
  • 登録不要・完全無料：ブラウザでURLを開くだけ。スマホでもPCでもすぐ対戦開始
  • 勝ち点2先取のテンポいいラウンド制

ご注意

BOMBはスカルにインスパイアされた当サイトのオリジナルゲームであり、スカル（Skull）本体が遊べるサービスではありません。スカルは各権利者の商品です。本家をオンラインで遊びたい方はBoard Game Arenaなどの公式配信プラットフォームをご利用ください。

こんな人にBOMBはおすすめ

  • スカルにハマったけど、オンラインで手軽にあの読み合いを楽しみたい人
  • 離れた友達と登録不要・無料で遊べる心理戦ゲームを探している人
  • 飲み会・オンライン飲みでURLひとつで始められるパーティゲームが欲しい人
  • 3人集まらなくても2人からブラフゲームを遊びたい人

POINT

スカル経験者なら、BOMBのルールは読んだ瞬間に理解できます。「自分のカードを先にめくる義務」を逆手に取る戦術や、入札で相手に高宣言を押し付ける立ち回りなど、スカルで培った読みがそのまま活きます。
