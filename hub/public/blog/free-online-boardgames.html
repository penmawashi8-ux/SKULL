2026.05.24 ｜ ボドゲ広場

「友達と気軽にオンラインで遊びたい」「アプリインストールなしでボードゲームを楽しみたい」そんな方に向けて、ボドゲ広場で遊べる無料・ブラウザ完結・登録不要のオンラインボードゲームを5つ厳選して紹介します。

おすすめ5選

No.1

BOMB

BOMB GAME

2〜6人 約20分 ブラフ 心理戦

爆弾かリンゴか——。場に積んだカードが爆弾かどうかをブラフで誤魔化しながら進む心理戦ゲーム。嘘をついて仲間を陥れる緊張感がクセになります。複数人で遊ぶと特に盛り上がるパーティゲームの定番。

今すぐ遊ぶ →

No.2

ぶたのしっぽ

PIG'S TAIL

1〜6人 約10〜20分 トランプ パーティ

円形に広げた裏向きカードを順番に1枚めくって中央に積んでいき、スート（マーク）が直前のカードと一致したら山をまるごと引き取るトランプゲーム。取るほど不利になり、最後に手持ちが最も少ない人が勝ち。数字一致も山取りになるオプションルールあり。

今すぐ遊ぶ →

No.3

ページワン

PAGE ONE

1〜4人 約15〜30分 トランプ 特殊カード

場のカードと同じマーク（スート）のカードを1枚ずつ出していき、手札をなくすことを目指す日本生まれのトランプゲーム。残り1枚になるカードを出すとき「ページワン！」の宣言を忘れると5枚ドローのペナルティ。唯一の特殊カード・ジョーカーは出した相手に4枚引かせる強力な一手になります。

今すぐ遊ぶ →

No.4

謀略

BORYAKU

2〜6人 約15〜30分 ブラフ 推理

持っていないキャラクターのカードでも「持っている」と宣言できるブラフゲーム。相手に疑われたらアウト、でもうまく騙せれば最後まで生き残れる。コンパクトながら深い駆け引きが楽しめます。

今すぐ遊ぶ →

No.5

バーチャル競馬

VIRTUAL KEIBA

1人〜 約5〜10分 競馬 バーチャル

馬を選んで予想して観戦するバーチャル競馬ゲーム。短時間でサクッと楽しめて、スキマ時間にも最適です。予想の読み合いを友達と楽しむのもおすすめ。1人でも複数人でも楽しめます。実際の賭けや金銭のやりとりは一切なく、純粋なゲームです。

今すぐ遊ぶ →

POINT

すべてのゲームはブラウザで動作するため、アプリのインストール不要。URLを友達に送るだけですぐにオンライン対戦が始められます。スマホ・PC・タブレットに対応しています。

どのゲームを選ぶ？

大人数でワイワイ盛り上がりたいなら

→ BOMB または 謀略。ブラフ・心理戦系は人数が多いほど盛り上がります。

運の要素を楽しみたいなら

→ ぶたのしっぽ。めくったカードのスートが揃ったら山取りという純粋な運ゲーで、誰でも逆転できる盛り上がりやすさが魅力です。

手持ちのカードを駆使して頭を使いたいなら

→ ページワン。同じマークだけ出せるルール＋ジョーカーの使いどころが勝敗を分けます。宣言忘れペナルティも緊張感を高めます。

1人でサクッと遊びたいなら

→ バーチャル競馬。1人でも楽しめて、5〜10分で終わります。
