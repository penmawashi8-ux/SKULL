# analysis — ブログ記事の数値を出すための解析スクリプト

ボドゲ広場のブログに載せている「データ解析」系記事の数値は、すべてここの
スクリプトで計算しています。記事を書き直すときや数字を疑われたときは、
これを実行し直せば再現できます。

Python 3.11 で動作確認。`verify_poko.py` のみ numpy が必要です。

## ファイル

| ファイル | 内容 | 対応記事 |
| --- | --- | --- |
| `gf2.py` | GF(2)（0と1だけの世界）での線形代数ユーティリティ | — |
| `poko_light.py` | ポコっとライトの全盤面解析。解ける盤面の割合・最短手数の分布 | `/blog/poko-light-complete-analysis.html` |
| `verify_poko.py` | 上の結果を総当たり計算と突き合わせる検証 | — |
| `marubatsu.py` | 〇×ゲームの全対局展開と完全解析 | `/blog/marubatsu-complete-analysis.html` |
| `babanuki.py` | ババ抜きのモンテカルロシミュレーション | `/blog/babanuki-seat-simulation.html` |
| `verify_babanuki.py` | 独立実装との突き合わせ検証 | — |
| `verify_babanuki_exact.py` | 小さいデッキでの厳密計算との突き合わせ検証 | — |
| `poko_results.json` / `babanuki_results.json` | 記事に載せた数値そのもの | — |

## 実行方法

```sh
python3 poko_light.py          # ポコっとライト：型・サイズ別の一覧
python3 verify_poko.py         # 検証（要 numpy、40秒ほど）
python3 marubatsu.py           # 〇×：全対局の集計と各種確率
python3 babanuki.py 200000     # ババ抜き：人数ごとに20万局（2〜3分）
python3 verify_babanuki.py     # 検証（40秒ほど）
python3 verify_babanuki_exact.py  # 厳密計算との突き合わせ（20秒ほど）
```

## 検証の方針

数字を記事に出す前に、必ず**独立した2通り以上の方法で同じ値が出ること**を
確認しています。

- **ポコっとライト**：線形代数による解析と、全パターン総当たりの2通り。
  3×3・4×4・5×5の全型（9パターン）で分布が完全一致。また5×5プラス型の
  最悪ケース15手は、海外のライツアウト研究で知られている値と一致する。
- **〇×**：全対局数 255,168 が完全解析の既知の値と一致する。
- **ババ抜き**：実装を2本書いて突き合わせ、さらに7枚の小さいデッキで
  「全ての配り方 × 全ての引き方」を確率つきで完全展開した厳密解と照合。

## 実装上の注意

`poko_light.py` の核（クワイエットパターン）の扱いに注意。剰余類の最小重みを
求めるとき、**核の基底ベクトルだけでなく、その全線形結合 2^k 個と比較する
必要があります**。基底としか比較しないと最短手数を過大に見積もります
（開発中に実際にこのバグを踏み、`verify_poko.py` の総当たり比較で発見しました）。

`verify_babanuki_exact.py` の厳密計算は再帰では書けません。ババ抜きの局面は
**循環しうる**ため（2人がジョーカーとペアの片割れを延々と回し続ける状態が
存在する）、素朴な再帰展開は停止しません。確率の塊を1手ずつ前進させ、
決着した分を吸収していく方式を使っています。
